RQ1 Efektivitas Distilasi Pengetahuan

Pengaruh Distilasi Pengetahuan terhadap Peningkatan Deteksi SATD

Rumusan Masalah:
“Bagaimana pengaruh penerapan distilasi pengetahuan pada arsitektur CodeBERT terhadap peningkatan kemampuan deteksi Self-Admitted Technical Debt dibandingkan model baseline?”
Target Metrik Macro-F1, MCC, AUC-PR
Metode Validasi Wilcoxon Signed-Rank Test (p < 0.05) & Cliff's Delta (|d| > 0.33)
Model Pembanding TextCNN, BiLSTM, Standard CodeBERT
Korpus Evaluasi D1 (Comments), D2 (Multi-Source Apache), D3 (Scientific Software)
RQ2 Ketahanan Deteksi Implisit

Efektivitas Deteksi SATD Implisit via Penyamaran Kata Kunci (Masking)

Rumusan Masalah:
“Sejauh mana Distilled CodeBERT efektif dalam mendeteksi Self-Admitted Technical Debt yang bersifat implisit ketika kata kunci eksplisit disamarkan atau dihilangkan?”
Target Metrik Degradasi Macro-F1 < 5%
Metode Validasi Evaluasi Komparatif pada Korpus Bertopeng [MASK]
Model Pembanding Model dengan Shortcut Learning (Gagal saat token TODO/FIXME dihapus)
Korpus Evaluasi D4 (Implicit Masked Test Suite - 4.000 sampel seimbang)
RQ3 Efisiensi Runner CI/CD

Akurasi Deteksi dan Efisiensi Komputasi pada Skenario CI/CD

Rumusan Masalah:
“Bagaimana perbandingan kinerja Distilled CodeBERT dengan model pembanding ditinjau dari akurasi deteksi dan efisiensi komputasi pada skenario implementasi CI/CD?”
Target Metrik Latensi CPU single-core τ < 30 ms & RAM puncak < 500 MB
Metode Validasi Simulasi ONNX Runtime CPU (Intel Xeon 1 vCPU @ 2.4 GHz, RAM 4 GB)
Model Pembanding DeepSeek-Coder-1.3B / 7B (Latensi > 1.200 ms, RAM > 3 GB)
Korpus Evaluasi Simulasi Runner CI/CD Pipeline Otomatis
