RQ1 • Akurasi & Efektivitas

Superioritas Distilled-CodeBERT vs Baseline

Apakah transfer penalaran dari Teacher DeepSeek-Coder-1.3B ke Student CodeBERT mampu mengungguli model konvensional (TextCNN, BiLSTM, Standard CodeBERT)?

F1-Macro > 0.75 MCC > 0.65 Wilcoxon & Cliff's Delta
Korpus Data: D1 (Java Comments), D2 (Multi-Source Apache), D3 (Scientific Software)
RQ2 • Ketahanan Semantik

Mitigasi Shortcut Learning pada Utang Implisit

Apakah model terdistilasi mampu mempertahankan deteksi ketika kata kunci penanda eksplisit (TODO, FIXME, HACK) disamarkan?

Degradasi F1 < 5% Integrated Gradients Attribution
Korpus Data: D4 (Implicit Masked Test Suite - 4.000 sampel seimbang)

Latensi & Efisiensi Runner Single-Core CPU
